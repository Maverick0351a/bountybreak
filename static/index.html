DESIGNED TO FAIL CLOSED

About & limits

Where data lives

All records are JSON files under the local data/ folder. They are ignored by Git. No account, telemetry, or third-party service is needed.

What runs

The demo sends exactly two GET requests to a synthetic server started inside this process on 127.0.0.1. It never accepts a user-supplied target URL and never follows redirects.

What is planning only

Bounty and internal engagements can hold hypotheses but cannot run the demo or launch ZAP, Nuclei, ffuf, or Shannon. A pass in planning does not authorize live traffic.

Evidence standard

Lab evidence saves status, body length, and SHA-256 digest, without response bodies or credentials. A passing negative control proves the lab check worked; it is not a vulnerability finding.
