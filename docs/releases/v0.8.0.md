# ScopeRook 0.8.0

ScopeRook 0.8.0 turns the local research desk into a continuous operating layer for bug bounty agents. A researcher can now preserve a portfolio of targets, resume the correct target from durable history, and carry scope, evidence, reporting, and outcome state through the whole workflow.

## Highlights

- Rank a cross-target portfolio and return one explainable next action.
- Preserve target profiles, exact assets, dated revisions, coverage sessions, and revisit dates.
- Score candidate payoff, duplicate risk, setup cost, proof strength, request budget, and stop conditions.
- Reduce reviewed Nuclei templates to non-executable intelligence metadata.
- Research current public vulnerability sources without treating an advisory as target evidence.
- Use 40 compact Daybreak-oriented MCP tools, three resources, and three prompts.
- Keep target traffic, scanners, credentials, and report submission outside the MCP.
- Verify 100 targets and 5,000 recorded sessions in a deterministic scale trial.

## Verification

The release candidate passes 45 unit tests on the local Python 3.11 environment. GitHub CI covers Python 3.11 and 3.12 on Windows and Ubuntu after publication.

## Upgrade

Back up the private data directory, replace the application files, and keep the same `--data-dir` argument. ScopeRook preserves incomplete or malformed legacy engagement records and marks them unavailable for hunting instead of silently hiding them.

## Known boundaries

ScopeRook 0.8.0 remains a private-beta candidate. It does not contain live target adapters, scanner execution, credential storage, report submission, signed distribution, executor receipts, or a deployed Oracle backend. A repository license must be selected before this candidate is published as a new public release.
