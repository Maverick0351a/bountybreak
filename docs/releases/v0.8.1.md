# ScopeRook 0.8.1

ScopeRook 0.8.1 is the Apache-2.0 community-core release of the independent bug bounty operating layer for Daybreak Blue.

This patch preserves the v0.8.0 continuous-hunting feature set and fixes reviewed-fixture integrity validation for ordinary Windows Git checkouts. The repository now declares LF line endings for hashed Python, JSON, Markdown, YAML, and SVG files, preventing Git's Windows line-ending conversion from changing a reviewed fixture after checkout.

## Included workflow

- Cross-target portfolio, durable history, exact assets, and deterministic next actions.
- Current public vulnerability intelligence and sanitized Nuclei-template metadata.
- Candidate economics, validation contracts, mandatory negative controls, and evidence manifests.
- Forty Daybreak-oriented MCP tools, three resources, and three prompts.
- Clear separation between the local operating layer and any separately authorized target executor.
