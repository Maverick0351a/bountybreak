# Changelog

All notable BountyBreak changes are recorded here.

## [Unreleased]

## [0.8.2] - 2026-10-05

- Renamed the product from ScopeRook to BountyBreak with an original horizon-and-target mark and a midnight/electric-blue interface.
- Moved a centered three-step Quickstart to the top of the README and dashboard so the first successful run is immediately visible.
- Changed the primary MCP namespace, resources, prompts, entry points, and release artifacts to `bountybreak`.
- Preserved the former `scoperook_*` calls and entry-point filenames as documented 0.8-line migration aliases.
- Kept Daybreak Blue as descriptive compatibility language while making the product's independent status explicit.

## [0.8.1] - 2026-10-05

- Enforced LF checkouts for hashed reviewed fixtures so integrity validation behaves consistently on Windows and Linux clones.
- Licensed the community core under Apache-2.0 and positioned ScopeRook as an independent Daybreak Blue bug bounty utility.

## [0.8.0] - 2026-10-05

- Added a continuous cross-target hunting portfolio with deterministic next-action ranking.
- Added target profiles, exact assets, dated revisions, coverage sessions, and durable history.
- Added candidate economics, validation contracts, request accounting, revisit scheduling, and separate financial facts.
- Added sanitized Nuclei-template metadata intake and current public-intelligence tools.
- Expanded the Daybreak MCP server to 40 compact tools, three resources, and three reusable prompts.
- Verified a deterministic 100-target, 5,000-session portfolio trial and 45 automated tests.

## [0.2.3] - 2026-10-04

- Disabled AI drafting by default and required explicit selection of a separate loopback model port.

## [0.2.2] - 2026-10-01

- Added prior-art context for local model drafts, improved model response handling, and clarified synthetic-lab results.

## [0.2.1] - 2026-09-30

- Added numbered navigation, a manual pre-run checklist, and refined the red-team interface.

## [0.2.0] - 2026-09-30

- Introduced the ScopeRook name, brand mark, and Windows launcher.

## [0.1.0] - 2026-09-30

- Initial local dashboard, public exploit-intelligence index, symbolic sandbox, optional local-model adapter, and bounded loopback lab check.
